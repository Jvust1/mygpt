# mygpt

一个用于构建、实验和迭代 GPT 应用的项目仓库。

## 当前状态

仓库目前处于初始化阶段，后续可以在这里逐步加入：

- GPT/LLM 调用层
- 对话与上下文管理
- Prompt 配置与版本管理
- 流式输出与错误处理
- 本地开发脚本和自动化测试

## 开发约定

- 使用清晰、可维护的目录结构组织代码
- API 密钥等敏感信息只通过环境变量提供
- 新功能应同时补充最小可运行示例和测试
- 提交信息使用简短、明确的动词开头，例如 `feat:`、`fix:`、`docs:`

## 建议的目录结构

```text
mygpt/
├── src/              # 应用源码
├── tests/            # 自动化测试
├── docs/             # 设计和使用文档
├── .env.example      # 环境变量模板，不包含真实密钥
├── .gitignore
└── README.md
```

## 本地开发

克隆仓库：

```bash
git clone https://github.com/Jvust/mygpt.git
cd mygpt
```

项目加入具体运行时和依赖后，再在这里补充安装、配置、启动和测试命令。
