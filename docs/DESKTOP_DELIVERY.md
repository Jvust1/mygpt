# mygpt Windows 本地桌面版

版本：2026.09.25-rc1。解压整个 ZIP，运行目录内的 mygpt.exe。不要只移动 EXE；保留 _internal 目录。程序内置 Python 与必要运行依赖，不需要安装 Python、Node 或 SDK。需要已有 Edge 或其他浏览器显示本机界面。

## 已有功能

安静陪伴与约拿组件、学习目标和自报计时、个人笔记编辑与本机保存、重启恢复、备份导出和非破坏性合并。使用临时选段工作台时，控制窗口必须先明确启用本次接收，且选段仍是 USER_SUPPLIED_UNVERIFIED；它不是 Book 已实时连接的证据。原有 Brain/TestModel 入口完整保留并明确标注为固定协议检查。

学习工作台默认不进行模型调用。可在“本机模型”页填写本机已安装的 Ollama 模型与端口，每次确认并单独发送下方文字。不下载模型，不将笔记自动发送，不接受任意远端 URL，不跟随重定向，不自动重试，也不执行工具调用。请确认本机服务配置的是本地模型，不是云模型或代理。底层服务自身的网络与资源行为由该服务控制。未独立验证真实模型的教学质量。

## 数据和退出

数据默认存放于 `%LOCALAPPDATA%\mygptDesktop\data\workspace.sqlite`。SQLite 每次成功修改保存一条版本快照；冲突的旧修订写入被拒绝，而不是覆盖其他窗口的新记录。没有在启动时读取旧版私有数据或其他应用。

笔记使用明确的“保存笔记”按钮。离开页面前先保存，未保存草稿可单独导出，发生冲突时先导出再重新加载。没有依赖浏览器 localStorage 保存个人笔记。不要为了排错删除数据目录。控制窗口的退出按钮关闭本机服务；关闭网页本身不会关闭服务。

计时以设备经过时间计算；关闭页面后继续计时，不等于实际注意力检测、有效学习分钟数或掌握度。备份恢复只合并已结束会话，不启动另一台设备的计时。备份内含个人笔记，须自行保管。导入同一备份不会重复生成相同副本。

## 边界

不进行系统级屏幕捕获、不自动控制其他应用、不冒充真人或建立自动云同步。约拿组件在应用界面内，不是经过实机验收的桌面全局透明悬浮窗。Book 实时授权链路与用户设备、真实模型的端到端验收仍单独保留。封装测试不等于整个长期项目已经完成。

程序未做商业 Authenticode 签名；不需要管理员权限。源码和测试在同批附件中，包内 PACKAGE_MANIFEST.json 列出文件身份。附带官方开源运行组件许可证；不附带任何字体文件。
